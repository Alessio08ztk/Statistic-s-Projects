Es 1 – Riemann and Lebesgue integration

Riemann: cut the domain [a, b] into n cells, pick one point in each cell, add up f(tag) × width. Lebesgue: cut the range of f into N horizontal strips [yk, yk+1), find the set of x whose value falls in the strip (the preimage), and add up yk × μ(preimage). With the strip's lower end as height this is the integral of a simple function below f, so it approaches the integral from below.

The catch for the Lebesgue side is the measure of the preimage. Here it is computed for each function by splitting [a, b] into stretches where f is monotone and finding the crossing point f(x) = t by bisection (about 40 evaluations per level and per stretch). Evaluations of f are counted for both methods, so the cost can be compared. For the two pathological functions nothing can be evaluated on a computer (every double is a rational number), so the Lebesgue value comes from measure theory and the Riemann tags are classified by hand: rational (left, midpoint, right) or "random real" (irrational with probability 1).

Convergence

What I see

Same value when both exist. For sin x, x², |x − 0.5|, sin x / x and the two step functions, both columns converge to the same number, which matches the theory: a bounded Riemann-integrable function is Lebesgue integrable and the two integrals coincide.

Accuracy and convergence. The midpoint Riemann sum is second-order for the smooth functions (slope ≈ −2 in the plot). The Lebesgue sum built from lower simple functions is only first-order: its error is at most (max f − min f)(b − a)/N, whatever the smoothness, so slope ≈ −1. Using the lower end of every strip costs us accuracy; a rule that picked a better representative in the strip would do better, but that is no longer the textbook definition. At a jump (the step functions) the Riemann error is O(1/n), coming from the one cell that contains the jump, and an even n hits the jump exactly at the cell boundary.

Cost. The Riemann sum needs n evaluations. The Lebesgue sum needs the preimage measure for N levels, and that is where almost all the evaluations go (roughly 40 × N × number of stretches here). It also needs structural knowledge of f (where it is monotone). For an arbitrary black-box f we can only sample it, and sampling the preimage on a fine grid is just a Riemann sum in disguise. So the Lebesgue idea is conceptually more powerful, but it is the Riemann one that is practical on a computer.

1/√x. The integrand is unbounded at 0. A left-endpoint sum evaluates f(0) = ∞ and breaks; midpoint works but converges slowly, error ≈ 0.59/√n, because the first cell carries the singularity. The Lebesgue side handles it naturally (the strips just go up), but the strips have to stop somewhere: with a cut-off at height √N the tail above it is lost and the error is again of order 1/√N.

Dirichlet. Riemann sums depend on the tags: with rational tags every term is 1 and the sum is 1, with irrational tags it is 0. The upper Darboux sum is 1 and the lower is 0 for every partition, so the function is not Riemann integrable. For Lebesgue the rationals are countable, so the preimage of {1} has measure 0 and the integral is 0.

Thomae. It is discontinuous exactly at the rational points (a set of measure zero), so by Lebesgue's criterion it is Riemann integrable, with integral 0. The Riemann sums with rational tags do go to 0, but erratically: they depend on how many divisors n has, roughly like (number of divisors of n)/n. With left tags I get 0.0059 for n = 1024 but only 0.0020 for the prime n = 1021, and 0.0017 for n = 4096, so the sequence is not even monotone. The Lebesgue sum is exactly 0 because every level set {f ≥ t}, t > 0, is finite.

Es 2 – Numerical computation of the normal CDF

Φ(x) = ∫−∞x φ(t) dt, with φ(t) = e−t²/2/√(2π). By symmetry Φ(−x) = 1 − Φ(x) and Φ(x) = ½ + ∫0x φ, so only the integral from 0 to |x| has to be computed. Methods implemented:

  • Trapezoid and Simpson on [0, |x|] with n panels.
  • Power series Φ(x) = ½ + φ(x)·(x + x³/3 + x⁵/(3·5) + …). Obtained by writing the Taylor series of e−t²/2 in the form that makes all terms positive; it is the erf series rearranged so that no cancellation happens for x > 0.
  • Continued fraction for the upper tail: Q(x) = 1 − Φ(x) = φ(x) / (x + 1/(x + 2/(x + 3/(x + …)))). Converges fast for large x and keeps relative accuracy in the tail, where 1 − Φ would lose all its digits.
  • Hybrid (my efficient version): series for |x| ≤ 2.5, continued fraction beyond.
  • Abramowitz–Stegun 26.2.17: a five-term polynomial in t = 1/(1 + 0.2316419x), absolute error below 7.5·10−8.

Why Φ is not an elementary function


Elementary functions are built from polynomials, exp, log and algebraic operations by composition. Liouville's theorem (1830s) says when an integral ∫ f(x) eg(x) dx, with f and g rational functions, is itself elementary: exactly when there is a rational function r such that


r′(x) + r(x)·g′(x) = f(x),   and then ∫ f eg = r eg.


For e−t²/2 we have f = 1 and g = −t²/2, so we would need a rational r with r′ − t·r = 1. Try it:


    

  • If r is a polynomial of degree d ≥ 0, then t·r has degree d + 1 ≥ 1 and r′ has lower degree, so r′ − t·r has degree d + 1 and cannot be the constant 1. (r = 0 gives 0 ≠ 1.)
    • 

  • If r has a pole of order k ≥ 1 at some point, r′ has a pole of order k + 1 there while t·r has order at most k, so r′ − t·r still has a pole and is not 1.
    • 



No such r exists, so ∫ e−t²/2 dt is not elementary, and neither is Φ. The same argument works for e−t², the integrand of erf. (The proof of the theorem itself is differential algebra and is in the notes linked in the assignment; here only the check for this integrand is shown.)



The error function, and why we still need numerics


The way out is to define a new function: erf(z) = (2/√π) ∫0z e−t² dt. Then Φ(x) = ½ (1 + erf(x/√2)) holds exactly, and in the calculator above the last line prints erf(x/√2) = 2Φ(x) − 1. This gives an exact analytic representation but not a formula we can evaluate: erf is just the integral under a new name, with no closed form in terms of elementary functions. To get numbers one still needs numerical integration, the power series (which converges for every x but loses digits through cancellation when |z| is large and alternating), the continued fraction in the tails, or rational/polynomial approximations like the one of Abramowitz–Stegun. Libraries combine several of these in different ranges, which is exactly what the hybrid does.


Conclusions from the experiments. Trapezoid converges as h² and Simpson as h⁴, so for the same number of evaluations Simpson is far better; but both are far more expensive than a few dozen operations. The A&S polynomial is the cheapest and good to about 7 digits, enough for many statistical purposes, but its error does not shrink. The series and continued fraction reach full double precision (about 1e-16) at a cost that depends on x, and the tail form is the one to trust for very small probabilities.
